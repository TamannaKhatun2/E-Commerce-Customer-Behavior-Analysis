# E-Commerce-Customer-Behavior-Analysis

Interactive **E-Commerce Customer Behavior Analysis Dashboard** built in **Microsoft Excel** to analyze revenue trends, customer behavior, product performance, and repeat customer insights using Pivot Tables, Pivot Charts, KPI Cards, and data visualization techniques.

---

## Project Overview

This dashboard helps track:

- Total Revenue
- Total Orders
- Unique Customers
- Repeat Customer Rate
- Average Order Value
- Monthly Revenue Trends
- Product-wise Units Sold
- Top Customers by Revenue
- Repeat vs New Customers

---

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- KPI Cards
- Excel Functions

---

## Key Insights

- High repeat customer rate indicates strong customer retention.
- Yoga Mats and Backpacks are top-selling products.
- Monthly revenue trends help identify peak sales periods.
- Customer segmentation provides insights into buyer behavior.
